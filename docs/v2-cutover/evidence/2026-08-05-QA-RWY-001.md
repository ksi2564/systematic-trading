## 실패를 폐기하지 않은 이력

직전 source `afcd6a3a67e571abcc8339c1fa1e7c2ba2929af0`의 push
[30989171055](https://github.com/ksi2564/systematic-trading/actions/runs/30989171055)와 PR
[30989173335](https://github.com/ksi2564/systematic-trading/actions/runs/30989173335)는 다른 4개 작업은
통과했지만 `ui-qa` planning 단계에서 실패했다. Linux CI의 320px D-10 검토
화면이 10,185px로 10,000px 상한을 185px 넘었다.

상한을 느슨하게 변경하지 않고, 320px에서 카드·단계·추적표·검토안의 간격과
타이포그래피 밀도를 조정했다. 검토안 value는 전체가 유지되고 내용이 잘리지 않으며,
키보드 이동·수동 복사 fallback·추적표 헤더 접근성 계약을 그대로 통과했다.
수정 source의 CI 최대는 9,513px로 내려갔고 두 lane 5/5가 통과했다.
