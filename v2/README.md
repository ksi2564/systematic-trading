# Wall-Ant v2

개인용 전략 연구와 자동매매 운영을 하나의 결정론적 평가기로 연결하는 모듈러
모놀리스다. 기존 Java 앱은 전환 검증이 끝날 때까지 그대로 유지한다.

## 현재 구현

- 기존 QQQM/QLD/TQQQ 낙폭 전략의 상태 전이와 VIX·200MA 보정
- 폼 기반 200일선 자산배분 전략과 공통 손절·익절·트레일링 보호 규칙
- 같은 평가기를 사용하는 단일 평가, CSV 백테스트, 고정 파라미터 롤링 검증, 내부 모의투자
- 다음 거래일 시가 체결, 배당·분할 반영, 멱등 주문 의도와 계좌별 필수 위험 한도
- 실행 기록을 증거로 요구하는 불변 전략 버전과 수동 생명주기
- 다계좌 전략 할당, 정지·수동 재개, 수동/한도형 자동 환전 프로필
- MySQL/Alembic 트랜잭션 스키마와 감사 기록
- 일봉·분봉 Parquet 저장과 출처·범위 카탈로그
- Cloudflare Access를 전제로 한 비공개 API 경계와 AES-256-GCM 자격증명 저장
- Discord Gateway의 상태 조회 및 정지 전용 명령
- 반응형 React 전략·연구·계좌·데이터·안전 콘솔

## 구조

```text
v2/
├── backend/   # FastAPI, 도메인, 백테스트, 저장소, 테스트
├── frontend/  # React/Vite 반응형 콘솔
├── examples/  # 연구 CSV 형식 예시
└── infra/     # 로컬 MySQL 및 향후 단일 VM 운영 템플릿
```

## 안전 기본값

- 실제 주문 어댑터는 `disabled`이며 주문 호출은 예외로 종료된다.
- `WALLANT_EXECUTION_ENABLED=true`는 애플리케이션 시작 단계에서 거부된다.
- 운영 배포, DNS, Cloudflare Access 정책, KIS 실계좌에는 아직 변경을 가하지 않는다.

각 하위 프로젝트의 README를 따라 로컬 실행과 검증을 수행한다.
운영 전환 조건과 금지 경계는 `docs/V2_RUNBOOK.md`를 기준으로 한다.
