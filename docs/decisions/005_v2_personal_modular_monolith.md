# ADR-005: 개인용 v2 모듈러 모놀리스 전환

## 상태

승인

## 배경

기존 Java/Spring 시스템은 공개 API, 운영 KPI, 전역 모드, 파라미터 레지스트리와
헥사고날 경계를 포함한다. 학습 프로젝트에는 가치가 있었지만, 한 사람이 여러 KIS
계좌와 전략을 연구·운영하는 현재 목적에는 변경 비용이 크다.

## 결정

- 기존 운영 앱과 같은 저장소의 `v2/`에 Python 3.12/FastAPI와 React/Vite 기반
  모듈러 모놀리스를 만든다.
- 백테스트, 롤링 검증, 내부 모의투자, 실전 시뮬레이션은 동일한 전략 평가기를
  사용한다.
- MySQL은 트랜잭션과 제어 상태, Parquet은 일봉·분봉 시계열을 담당한다.
- 전략 정의는 불변 버전이며 자동 승격하지 않는다. 계좌마다 하나의 승인된 전략
  버전을 활성화한다.
- 공개 API와 공개 성과 화면은 만들지 않는다. 최종 웹 경계는
  `app.wall-ant.com`의 Cloudflare Access다.
- 실제 주문은 섀도 검증과 별도 승인 전까지 구조적으로 비활성화한다.

## 안전 불변조건

- 동일 주문 의도는 같은 멱등키를 갖는다.
- 상태 불명, 필수 데이터 오류, 위험 한도 위반은 계좌 정지를 요구한다.
- Discord는 조회와 정지만 허용하며 재개·승격·설정 변경은 웹에서만 한다.
- KIS 자격증명은 AES-256-GCM으로 암호화하고 마스터 키는 DB 밖에 둔다.
- 현재 MVP는 기존 운영 DB 이관을 제공하지 않으며 원본 DB를 변경하지 않는다. 이관은
  원본 식별자와 계좌 범위를 포함한 별도 설계와 승인을 거친다.

## 결과

Java 앱은 v2 전환 후 30일 동안 주문이 차단된 롤백 수단으로 유지한다. v2는 기능별
모듈 경계를 가지지만 별도 서비스와 메시지 브로커는 도입하지 않는다.
