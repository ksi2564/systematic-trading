## 1. 전략 개요와 투자 가설

현재 전략은 QQQ를 기준 자산으로 삼아 낙폭 구간과 회복 구간을 상태화하고, 그 상태에 따라 QQQ, QLD, TQQQ의 목표 비중을 조정하는 규칙형 리밸런싱 전략이다.

전략 가설은 다음과 같다.

- 단순 보유보다 상태 기반 비중 조절이 시장 하락과 회복 구간 대응을 구조화할 수 있다.
- 낙폭이 커질수록 비중을 점진적으로 조정하면 과도한 단일 진입을 피할 수 있다.
- 회복 구간에서는 공격적인 레버리지보다 보수적인 정상화가 유리할 수 있다.

위 가설은 현재 제품의 설계 기준이며, 백테스트와 실거래 성과를 통한 정량 검증은 별도 보강이 필요하다.

## 2. 운용 대상 자산과 선택 이유

### 현재 기준

- `QQQ`: 기본 노출 자산
- `QLD`: 중간 레버리지 자산
- `TQQQ`: 고레버리지 자산

### 목표 정책

현재 문서 체계에서는 세 자산 조합을 전략의 고정 전제로 둔다. 제품 범위를 불필요하게 넓히지 않고, 상태 전이와 리스크 제어 로직을 이 조합에 최적화한다.

### 갭/후속 과제

- 각 자산 선택의 정량 근거는 별도 성과 분석 문서로 보강할 필요가 있다.
- 환율, 세금, 장기 보유 비용 등 운영 현실 비용은 현재 전략 문서에 충분히 반영되지 않았다.

## 3. 상태 모델

전략 상태는 아래 필드를 중심으로 관리한다.

| 필드 | 의미 |
| :--- | :--- |
| `asOfDate` | 전략 상태 기준 일자 |
| `ath` | 전고점 종가 |
| `lastClose` | 최근 종가 |
| `drawdownPct` | 현재 낙폭 |
| `maxDrawdownPctSinceAth` | 전고점 이후 최대 낙폭 |
| `ddBucket` | 낙폭 구간 |
| `phase` | 전략 단계 |
| `targetWeights` | 목표 비중 |
| `strategyOn` | 전략 활성화 여부 |
| `version` | 전략 버전 |

초기 상태가 없으면 최근 1년 QQQ 종가에서 ATH를 계산해 초기 상태를 생성한다.

## 4. DD 구간 정의

| 구간 | 조건 |
| :--- | :--- |
| `LESS_THAN_15` | DD < 15% |
| `FROM_15_TO_25` | 15% <= DD < 25% |
| `FROM_25_TO_35` | 25% <= DD < 35% |
| `FROM_35_TO_45` | 35% <= DD < 45% |
| `MORE_THAN_45` | DD >= 45% |

## 5. 전략 단계 정의

| 단계 | 정의 |
| :--- | :--- |
| `NORMAL` | 해당 ATH 이후 최대 DD가 15% 미만 |
| `DRAWDOWN` | 최대 DD가 15% 이상이고 현재 DD가 10% 초과 |
| `RECOVERY` | 최대 DD가 15% 이상이고 현재 DD가 10% 이하 |

추가 규칙:

- 전고점 돌파 시 ATH를 갱신하고 DD와 최대 DD를 0으로 리셋한다.
- 현재 DD가 10% 초과 15% 미만인 구간에서는 이전 목표 비중을 유지한다.

## 6. 목표 비중

| 상태/구간 | QQQ | QLD | TQQQ |
| :--- | ---: | ---: | ---: |
| `NORMAL` 또는 DD < 15% | 100 | 0 | 0 |
| DD 15%~25% | 60 | 30 | 10 |
| DD 25%~35% | 40 | 40 | 20 |
| DD 35%~45% | 30 | 30 | 40 |
| DD 45% 이상 | 20 | 20 | 60 |
| `RECOVERY` | 70 | 30 | 0 |

## 7. Circuit Breaker 정책

### 현재 구현

- VIX 필터와 200MA 필터를 사용한다.
- 200MA 필터는 `QQQ 종가 < QQQ 200일 이동평균`일 때 TQQQ 비중을 한 단계 낮춘다.
- VIX 필터는 `VIX >= 35`를 트리거 조건으로 사용한다.
- 적용 순서는 200MA 조정 후 VIX 확인 순서다.

### 목표 정책

- 200MA 필터는 공격적인 버킷을 한 단계 낮추는 보수적 제어 장치로 유지한다.
- VIX 필터는 고변동성 구간에서 레버리지 확대를 명시적으로 제한해야 한다.
- 두 필터는 단순 플래그가 아니라 목표 비중 조정 결과에 실제 반영되어야 한다.

### 갭/후속 과제

- 현재 구현에서는 VIX 트리거는 계산되지만, 이전 비중(`prevWeights`)이 전달되지 않아 실제 비중 제한이 적용되지 않는다.
- 향후에는 VIX 트리거 시 “이전보다 공격적 확대 금지”를 상태 기반으로 확정해야 한다.

## 8. 리밸런싱 판단 규칙

### 현재 구현

- `strategyOn=true`여야 한다.
- 총자산이 0보다 커야 한다.
- 실제 비중과 목표 비중 차이가 허용 오차를 넘는 종목이 하나 이상 있어야 한다.
- 기본 허용 오차는 `trading.strategy.tolerance-pct = 5.0`이다.
- 기본 우선순위는 매도 `TQQQ -> QLD -> QQQ`, 매수 `QQQ -> QLD -> TQQQ`다.

### 목표 정책

- 허용 오차는 과도한 소액 리밸런싱을 줄이기 위한 기본 운영 장치로 유지한다.
- 매도는 공격 자산부터 줄이고, 매수는 보수 자산부터 채우는 순서를 기본값으로 유지한다.
- Circuit Breaker가 활성화되면 리밸런싱 판단 결과에 명확한 영향이 있어야 한다.

### 갭/후속 과제

- 허용 오차 5%의 근거와 적정성 검증이 아직 문서화되지 않았다.
- 우선순위와 tolerance는 전략 성과, 수수료, 슬리피지 관점의 검증이 필요하다.

## 9. 주문 가격 정책

### 현재 구현

- 주문 수량 계산 기준 가격은 `RealtimePriceProvider`의 최근 체결가(`last price`)다.
- 기본 주문 버퍼는 `ExecutionJobCreateService`에서 0.3%로 고정된다.
- `PricingConfig`에는 매수/매도 버퍼 0.5%, 수수료 0.25%가 정의되어 있다.
- 실제 주문 가격 계산에는 기본 버퍼 0.3%와 수수료만 직접 반영된다.
- 현재 구현은 최우선 호가(best ask / best bid)를 사용하지 않는다.

### 목표 정책

- 정규장 기본 주문가는 최근 체결가보다 현재 호가를 우선 기준으로 삼아야 한다.
- 매수는 best ask, 매도는 best bid를 기준 가격으로 사용해야 한다.
- 기본 버퍼는 0% 또는 1~2틱 수준의 최소 보정만 허용해야 한다.
- 수수료는 주문 가능 수량과 예상 체결 금액 계산에 별도로 반영해야 한다.

### 갭/후속 과제

- 현재 구현은 최근 체결가와 퍼센트 버퍼에 의존해 슬리피지 비용을 만들 가능성이 있다.
- `PricingConfig`의 0.5% 버퍼 설정과 실제 주문 생성의 0.3% 기본 버퍼가 일치하지 않는다.
- 호가 기반 주문 정책이 구현되지 않았으므로 시세 공급 인터페이스 확장이 필요하다.

## 10. 재시도 정책

### 현재 구현

- 최대 3회 시도한다.
- 시도 간 대기 시간은 기본 10초다.
- 버퍼 시퀀스는 0.3% -> 0.5% -> 0.8%다.
- 부분 체결 시 남은 수량만 재주문한다.
- 미체결 수량은 취소 후 다음 시도를 한다.
- 다만 재시도 시 새 주문 객체는 수량만 변경하고 기존 `refPrice`, `limitPrice`를 그대로 사용한다.

### 목표 정책

- 정규장 기준 대기 시간은 짧고 예측 가능해야 한다.
- 재시도 직전 현재 호가를 다시 조회해 기준 가격을 새로 잡아야 한다.
- 최초 주문은 추가 버퍼 없이 제출하고, 이후에도 틱 단위의 최소 보정만 허용해야 한다.
- 큰 퍼센트 단위 버퍼 확대는 기본 정책으로 사용하지 않아야 한다.

### 갭/후속 과제

- 현재 구현은 버퍼 값을 로그에는 남기지만 실제 주문 가격을 갱신하지 않는다.
- 대기 시간 10초와 퍼센트 버퍼 확대는 목표 정책과 다르다.
- 재시도 정책을 호가 재조회 기반으로 재설계해야 한다.

## 11. 전략 리스크와 한계

- 최근 체결가 기반 주문은 체결 품질을 보장하지 않는다.
- 외부 시세 지연 또는 결측은 잘못된 상태 계산과 주문 판단으로 이어질 수 있다.
- 레버리지 ETF 비중 확대는 하락 구간에서 손실 확대를 동반한다.
- 성과 지표와 사후 분석 체계가 약하면 전략 개선이 감각 의존으로 흐를 수 있다.

## 12. 향후 검증 필요 항목

- DD 구간과 목표 비중의 백테스트 근거
- tolerance와 우선순위 설정의 적정성
- Circuit Breaker 파라미터의 효과
- 가격 정책과 슬리피지 영향
- NAV, 월별 PnL, MDD 기반 성과 검증 체계
