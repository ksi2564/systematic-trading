## 실패·대체 이력

역사적 문서 전용 후속 커밋 `d864b0e6081423b101a8aeb7e306c8d688097673`의 push
[30976154244](https://github.com/ksi2564/systematic-trading/actions/runs/30976154244)와 PR
[30976156222](https://github.com/ksi2564/systematic-trading/actions/runs/30976156222)는
`backend`, `frontend`, `legacy-strategy-parity`, `ui-qa`가 통과했지만 `infra`가 실패해
현재 정본으로 사용하지 않는다. 두 run 모두 C0 verifier와 51개 unit test까지 통과한 뒤,
`documentation_contract_test.sh:116`의 오래된 exact-string 단언이
`C0 gate 51/51 PASS`를 요구했지만 갱신된 `DELIVERY_TRACE.md`는
`C0 gate 양성/음성 51건`으로 표현해 silent grep가 fail-closed로 종료됐다. 배포·런타임
실패가 아니며 그 run의 artifact도 현재 증적으로 승격하지 않았다.

후속 source `b2037f3`에서는 이 stale exact-string 단언을 현재 용어로 교체하는 동시에 승인
순서를 전 문서·보드에 명시하고, 별도 C0-B 수집 승인 기록·접근 방법·12개 정제
capture·snapshot/diff·결과 재승인·C2 보호 tree를 검사하는 계약을 51개에서 55개로
확장했다. 그 결과가 위 새 source/PR run이다.

1. [기획 검토 보드](../review-board/index.html)에서 D-01부터 D-10까지 순서대로 답한다.

4. 다음 범위를 **별도로** 승인한다:
   `대상=12개; 접근방법=GitHub Actions PROD SSH로 운영 호스트 shell 조회·DB SELECT;
   권한=읽기 전용; 정제=필수; 저장위치=docs/v2-cutover/evidence/c0b/;

6. 그 재승인 뒤에만 C2 자동 섀도 runtime·데이터 adapter·comparator·화면 개발을 시작한다.
